# Nexoryna

Professional company website for an AI & blockchain studio.

**Stack:** Next.js (App Router) · ready for Vercel  
**Focus:** Blockchain & tokens · AI + on-chain products · Smart contracts

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Import this repo in Vercel.
2. Optional env: `NEXT_PUBLIC_SITE_URL` = your production URL.

Contact form uses `POST /api/contact` in this app. No separate backend.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm start` | Run production server |
| `npm run lint` | Lint |
